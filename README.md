# Stablecoin Ecosystem

Research workspace for stablecoin infrastructure, listed equities, tokens, and ecosystem risks.

## Contents

- `equities_research.md`, `tokens_research.md`, `risk_research.md`: research notes.
- `*_sources.json`: supporting source registers.
- `crcl_valuation_experiment.csv`: valuation experiment.
- `research/`: discovery notes, snapshots, paper watchlist, and data collection script.

Research and paper-trading decision support only. Existing research claims require verification before use; repository publication does not validate them.

Raw downloads under `research/raw/`, credentials, and local runtime files are excluded from version control.
